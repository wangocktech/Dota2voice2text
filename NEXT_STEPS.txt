ПОРЯДОК ДЕЙСТВИЙ

1. Сначала очистить GitHub-репозиторий и обновить README:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\CLEAN_REPO_AND_UPDATE_README.ps1

2. Затем собрать Windows installer:

.\BUILD_INSTALLER.ps1

3. Проверить установщик:
- установка без администратора;
- запуск;
- русский Voice-to-Text;
- RU→EN;
- tray;
- сохранение настроек;
- повторная установка поверх текущей версии;
- удаление через Windows «Установленные приложения».

4. Если всё нормально — добавить Setup.exe в уже существующий Release v0.2.0:

.\PUBLISH_SETUP.ps1
