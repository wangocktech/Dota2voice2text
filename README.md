## 📖 О проекте

**Dota2voice2text** — приложение для Windows, которое преобразует речь с микрофона в текст и автоматически вставляет её в чат **Dota 2**.

Программа работает по принципу Push-to-Talk:

1. Зажимаешь назначенную кнопку.
2. Говоришь сообщение.
3. Отпускаешь кнопку.
4. Программа распознаёт речь.
5. Открывает нужный чат Dota 2.
6. Вставляет распознанный текст.
7. Ты проверяешь сообщение и самостоятельно нажимаешь **Enter**.

Также будет доступна опциональная автоматическая отправка сообщения.

## 🎮 Как это работает

### Командный чат

Пример бинда:

`	ext
MOUSE5
`

Сценарий:

`	ext
MOUSE5 DOWN
      ↓
Начало записи

"Поставьте варды"

MOUSE5 UP
      ↓
Остановка записи
      ↓
Распознавание речи
      ↓
Enter
      ↓
Вставка текста

"Поставьте варды"
`

После этого сообщение остаётся в строке чата.

Для отправки пользователь самостоятельно нажимает **Enter**.

---

### Общий чат

Для общего чата приложение открывает его через:

`	ext
SHIFT + ENTER
`

После чего вставляет распознанное сообщение.

## 🧠 Распознавание речи

Для локального Speech-to-Text планируется использование **Whisper / faster-whisper**.

Распознавание происходит локально на компьютере пользователя.

Это означает:

- не нужен API-ключ;
- нет оплаты за каждое распознавание;
- голос не обязательно отправлять на сторонние серверы;
- программа может работать без постоянного подключения к интернету.

## 🛠️ Технологии

Проект разрабатывается на **Python**.

Планируемый стек:

| Компонент | Технология |
|---|---|
| GUI | PySide6 |
| Запись микрофона | sounddevice |
| Speech-to-Text | faster-whisper |
| Глобальные бинды | pynput / WinAPI |
| Ввод в Dota 2 | Windows Input API |
| Настройки | JSON |
| Сборка | PyInstaller |

## 💻 Запуск из исходного кода

### Требования

- Windows 10 / 11
- Python 3.11+

Клонирование:

`powershell
git clone https://github.com/wangocktech/Dota2voice2text.git
cd Dota2voice2text
`

Создание виртуального окружения:

`powershell
python -m venv .venv
`

Активация:

`powershell
.\.venv\Scripts\Activate.ps1
`

Установка зависимостей:

`powershell
pip install -r requirements.txt
`

Запуск:

`powershell
python app.py
`
