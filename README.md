## 📖 О проекте

**Dota2voice2text** — бесплатное приложение для Windows, которое преобразует речь с микрофона в текст и вставляет её в командный или общий чат **Dota 2**.

Программа работает по принципу Push-to-Talk:

1. Зажмите назначенную кнопку.
2. Скажите сообщение.
3. Отпустите кнопку.
4. Программа распознает речь локально на вашем компьютере.
5. Исправит известные игровые термины.
6. Добавит пунктуацию и регистр.
7. Откроет нужный чат Dota 2 и вставит готовый текст.

По умолчанию сообщение **не отправляется автоматически** — после вставки текста вы самостоятельно нажимаете `Enter`.

При желании в настройках можно включить автоматическую отправку.

## 🎮 Как это работает

### Командный чат

По умолчанию:

```text
MOUSE5
```

Пример:

```text
MOUSE5 DOWN
     ↓
Запись микрофона

"Поставьте варды, пожалуйста"

MOUSE5 UP
     ↓
Распознавание речи
     ↓
Исправление игровых терминов
     ↓
Пунктуация и регистр
     ↓
Открытие командного чата
     ↓
"Поставьте варды, пожалуйста."
```

Если автоматическая отправка выключена, сообщение остаётся в поле ввода.

Для отправки просто нажмите:

```text
Enter
```

---

### Общий чат

По умолчанию:

```text
MOUSE4
```

После отпускания бинда программа открывает общий чат Dota 2, вставляет распознанный текст и оставляет его в поле ввода.

Если включена настройка **«Автоматически отправлять сообщение»**, программа дополнительно нажмёт `Enter`.

## 🧠 Распознавание речи

Основной движок распознавания — **GigaAM v2**, работающий локально через `sherpa-onnx`.

Преимущества:

- не нужен API-ключ;
- нет оплаты за запросы;
- голос не отправляется на сторонние серверы;
- после загрузки приложения постоянное подключение к интернету для распознавания не требуется;
- короткие игровые сообщения обрабатываются быстро.

После распознавания текст проходит дополнительную обработку:

```text
Голос
  ↓
GigaAM v2
  ↓
Dota-словарь
  ↓
Коррекция известных терминов
  ↓
RUPunct
  ↓
Готовый текст
  ↓
Dota 2
```

Пример:

```text
Распознано:
алло поставьте ворды пожалуйста срочно

После обработки:
Алло, поставьте варды, пожалуйста, срочно.
```

## 📥 Установка

### Вариант 1 — готовая версия

Рекомендуемый способ.

1. Откройте раздел **Releases**.
2. Скачайте архив:

```text
Dota2voice2text-v0.1.0-windows-x64.zip
```

3. Распакуйте архив в любую папку.
4. Запустите:

```text
Dota2voice2text.exe
```

Python и дополнительные зависимости устанавливать не требуется.

> Не запускайте `.exe` прямо из ZIP-архива. Сначала полностью распакуйте его.

## 🚀 Первый запуск

1. Запустите `Dota2voice2text.exe`.
2. Выберите нужный микрофон.
3. Назначьте бинд командного чата.
4. Назначьте бинд общего чата.
5. При необходимости включите автоматическую отправку.
6. Нажмите **«Запустить»**.
7. Дождитесь статуса **«Готов»**.
8. Переключитесь в Dota 2 и используйте назначенные Push-to-Talk кнопки.

При старте программе требуется некоторое время на загрузку локальных моделей в память.

## 🔒 Конфиденциальность

Распознавание речи выполняется **локально на компьютере пользователя**.

Dota2voice2text не требует отправки записанного голоса в облачный Speech-to-Text API.

Приложение не предназначено для хранения записей микрофона после обработки.

---

## ⚡ Производительность

Цель проекта — получить готовый текст максимально быстро после отпускания Push-to-Talk кнопки.

Обычная цепочка:

```text
Отпустил кнопку
      ↓
Распознавание
      ↓
Коррекция
      ↓
Пунктуация
      ↓
Вставка в Dota 2
```

Производительность зависит от:

- процессора;
- длительности фразы;
- выбранного микрофона;
- фоновой нагрузки системы.

Целевой максимум задержки после отпускания кнопки — **до 5 секунд**, а на коротких фразах обработка обычно занимает существенно меньше времени.

## 🔔 Системный трей

Если включено:

```text
Сворачивать в системный трей
```

то при закрытии или сворачивании окна приложение может продолжить работу в фоне.

Через меню иконки в трее можно:

- открыть окно;
- запустить / остановить распознавание;
- полностью выйти из приложения.

При желании системные уведомления можно отключить.

## 💻 Запуск из исходного кода

### 1. Клонирование

```powershell
git clone https://github.com/wangocktech/Dota2voice2text.git
cd Dota2voice2text
```

### 2. Создание виртуального окружения

```powershell
python -m venv .venv
```

### 3. Активация

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

### 4. Установка зависимостей

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 5. Запуск

```powershell
python app.py
```

## 📦 Сборка Windows

Установите PyInstaller:

```powershell
pip install pyinstaller
```

Пример сборки:

```powershell
pyinstaller `
  --noconfirm `
  --clean `
  --windowed `
  --name "Dota2voice2text" `
  --collect-all sherpa_onnx `
  --add-data "models\sherpa-onnx-nemo-ctc-giga-am-v2-russian-2025-04-19;models\sherpa-onnx-nemo-ctc-giga-am-v2-russian-2025-04-19" `
  --add-data "models\rupunct-small-onnx;models\rupunct-small-onnx" `
  --add-data "data;data" `
  --add-data "assets;assets" `
  app.py
```

Готовая сборка появится в:

```text
dist\Dota2voice2text\
```
