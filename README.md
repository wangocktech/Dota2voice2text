## 📖 Что это

**Dota2voice2text** — бесплатное приложение для Windows, которое преобразует речь с микрофона в текст и вставляет её в **командный** или **общий чат Dota 2**.

Приложение работает по принципу Push-to-Talk:

1. Зажмите назначенную кнопку.
2. Скажите сообщение.
3. Отпустите кнопку.
4. Речь локально распознается на компьютере.
5. Dota-термины автоматически исправляются.
6. Добавляются пунктуация и регистр.
7. При необходимости сообщение локально переводится с русского на английский.
8. Готовый текст вставляется прямо в чат Dota 2.

По умолчанию программа **не нажимает Enter за пользователя**. Автоматическую отправку можно включить отдельно.

## 🎮 Управление

По умолчанию:

| Действие | Кнопка |
|---|---|
| Командный чат | `MOUSE5` |
| Общий чат | `MOUSE4` |

Бинды можно изменить прямо в приложении.

### Пример

Вы говорите:

```text
Поставьте варды на миду, у них нет байбека.
```

Без перевода:

```text
Поставьте варды на миду, у них нет байбека.
```

С включенным RU → EN:

```text
Place wards mid, they have no buyback.
```

## 🧠 Как устроена обработка

```text
Микрофон
   ↓
GigaAM v2
   ↓
Dota-коррекция
   ↓
RUPunct
   ↓
[опционально] RU → EN
   ↓
Windows SendInput
   ↓
Dota 2
```

Основная обработка выполняется локально. Для работы перевода модель скачивается один раз и затем также работает локально.

## 🌐 Перевод RU → EN

Перевод можно включить отдельной галочкой:

```text
☐ Автоматически переводить на английский
```

При первом включении приложение предложит скачать модель перевода.

Модель хранится отдельно от программы:

```text
%LOCALAPPDATA%\Dota2voice2text\models\
```

Поэтому она:

- не увеличивает размер основной сборки;
- не скачивается тем, кому перевод не нужен;
- не теряется при обычном обновлении программы.

В качестве основы используется `Helsinki-NLP/opus-mt-ru-en`, конвертированный в CTranslate2 INT8.

## ⚡ Скорость

Проект ориентирован на короткие игровые сообщения.

Типичный pipeline:

```text
ASR → коррекция → пунктуация → перевод → ввод
```

На производительность влияют процессор, длина фразы и фоновая нагрузка.

Цель проекта — удерживать полную задержку после отпускания Push-to-Talk **ниже 5 секунд**. На коротких фразах она обычно значительно меньше.

## 📥 Установка

### Готовая версия

Откройте:

**[GitHub Releases](https://github.com/wangocktech/Dota2voice2text/releases)**

Скачайте актуальную Windows-сборку и распакуйте её или используйте `Setup.exe`, если он доступен для выбранного релиза.

После установки/распаковки запустите:

```text

```

## 🚀 Первый запуск

1. Выберите микрофон.
2. Проверьте бинды Team Chat и All Chat.
3. При необходимости включите автоматическую отправку.
4. При необходимости включите перевод на английский.
5. Нажмите **«Запустить»**.
6. Переключитесь в Dota 2.
7. Зажмите Push-to-Talk, скажите фразу и отпустите кнопку.

## 🔒 Конфиденциальность

Распознавание речи и перевод выполняются локально.

Dota2voice2text не требует облачного Speech-to-Text API и не отправляет голосовые записи на сервер для распознавания.

Интернет используется только для функций, которым он действительно нужен, например:

- скачивание модели перевода;
- проверка обновлений;
- загрузка новой версии с GitHub Releases.

## 🛠️ Технологии

| Компонент | Используется |
|---|---|
| GUI | PySide6 / Qt 6 |
| Микрофон | sounddevice / WASAPI |
| Speech-to-Text | GigaAM v2 |
| ASR runtime | sherpa-onnx |
| Пунктуация | RUPunct / ONNX Runtime |
| RU → EN | CTranslate2 + SentencePiece |
| Dota-коррекция | RapidFuzz + собственные словари |
| Глобальные бинды | pynput |
| Ввод текста | Windows SendInput |
| Сборка | PyInstaller |

## 💻 Запуск из исходного кода

Для разработки используется Python 3.13.

```powershell
git clone https://github.com/wangocktech/Dota2voice2text.git
cd Dota2voice2text

py -3.13 -m venv .venv313
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv313\Scripts\Activate.ps1

python -m pip install --upgrade pip
pip install -r requirements.txt
```

Локальные ASR/Punctuation-модели не хранятся в Git из-за размера. Готовая пользовательская сборка уже содержит необходимые модели распознавания и пунктуации.

Запуск:

```powershell
python app.py
```

## 📦 Сборка Windows

После подготовки локальных моделей:

```powershell
.\BUILD_WITH_TRANSLATION.ps1
```

Результат:

```text
dist\Dota2voice2text\Dota2voice2text.exe
```

Модель RU → EN **не встраивается** в основную сборку и скачивается приложением отдельно.
