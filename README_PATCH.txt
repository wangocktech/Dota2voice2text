Dota2voice2text — RU -> EN translation patch

Что уже сделано:
- исправлен controller.py после ручных вставок;
- добавлена галочка "Автоматически переводить на английский";
- настройка сохраняется в config.json;
- при выключенной галочке приложение работает как раньше;
- при включенной галочке после GigaAM + RUPunct запускается локальный RU -> EN;
- переводчик загружается только когда он нужен;
- используется CTranslate2 INT8;
- добавлен Dota glossary;
- в статусе отображается "Перевожу на английский...";
- итоговая задержка продолжает считаться от отпускания PTT до вставки в Dota.

Установка:
1. Распакуй этот ZIP.
2. Запусти INSTALL_TRANSLATION.ps1.
3. Дождись строки "ГОТОВО".
4. Запусти приложение командой, которую покажет скрипт.
5. Поставь галочку "Автоматически переводить на английский".
6. Нажми "Запустить" и протестируй в Dota.

Если PowerShell запрещает запуск:
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\INSTALL_TRANSLATION.ps1

Для будущей сборки EXE:
.\BUILD_WITH_TRANSLATION.ps1

Важно:
Модель OPUS-MT RU->EN скачивается/конвертируется один раз, если её ещё нет.
Перед заменой файлов INSTALL_TRANSLATION.ps1 автоматически создаёт backup.
