# Changelog

## v0.3.3 — 2026-09-21

### Accuracy hotfix
- Убрана опасная fuzzy-коррекция по всему `dota_terms.txt`.
- Исправлены ложные замены корректных слов вроде `тест → текст`, `помогите → помогут`, `пошел → прошел`, `люблю → любую`.
- Fuzzy-коррекция теперь работает только по явным Dota-алиасам.
- Добавлены безопасные алиасы `мит → мид`, `сф → SF`, варианты Snapfire.
- Pre-roll увеличен до 300 мс, tail до 300 мс.
- Сохранение границ речи при trimming стало консервативнее.


### Adaptive ASR
- Добавлен двухпроходный Adaptive ASR с latency budget.
- Добавлены 180 мс pre-roll и 220 мс tail для PTT.
- Аудиопоток теперь держится открытым во время работы контроллера.
- Добавлены нормализация аудио и консервативное удаление тишины.
- Добавлен Dota-aware rescoring кандидатов с пользовательским словарём.
- Добавлены confidence estimate и режимы FAST / VERIFY / ACCURACY_RETRY / FAST_DEADLINE.
- Распознавание имеет deadline 2.85 сек. после отпускания PTT, оставляя запас до 3 сек.
- Добавлена защита от зависшего inference: второй экземпляр decoder не запускается поверх незавершённого timeout-прохода.
- Последние ASR-метрики сохраняются в `asr_latest.json` и добавляются в диагностику.
